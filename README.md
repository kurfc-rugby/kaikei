# KURFC 会計（ホーム画面のアプリの入口）

鹿児島大学ラグビー部の会計アプリを、スマホのホーム画面に置いて使うための入口のページです。
https://kurfc-rugby.github.io/kaikei/

- 会計アプリ本体（Google Apps Script のWebアプリ）を全画面で表示するだけのページです。会計のデータ・アプリのコードはここにはありません。
- ホーム画面への追加（PWA）と、スマホへの通知（Web Push）の受け取りを受け持ちます。
- 通知は会計アプリのサーバーが送り、中身は Service Worker（`sw.js`）がサーバーに取りに行って表示します。

| ファイル | 中身 |
|---|---|
| `index.html` | 入口の画面（会計アプリを iframe で表示） |
| `shell.js` | 会計アプリとのメッセージのやり取り・通知の登録・ホーム画面への追加 |
| `sw.js` | 通知を受け取って表示する・押したらその画面を開く |
| `config.js` | 会計アプリのURL（Apps Script のデプロイが変わったらここを直す） |
| `manifest.webmanifest`・`icons/` | ホーム画面のアイコンと名前 |

版を上げるときは、`sw.js` の `VERSION` と `index.html` の `?v=` を一緒に変えます。
